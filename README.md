# 🍏 Apple Products Store

Interface web inspirada no design do site da Apple, desenvolvida com **React**, **Vite** e **Tailwind CSS**.  
O objetivo do projeto é criar uma experiência visual limpa, responsiva e minimalista, com foco na organização de produtos Apple e aplicação de boas práticas de **front-end moderno**.

---

## 💻 Tecnologias Utilizadas

- **React** – Biblioteca JavaScript para construção de interfaces.
- **Vite** – Bundler rápido e moderno para aplicações web.
- **Tailwind CSS** – Framework CSS utilitário para estilização rápida e responsiva.
- **JavaScript/JSX** – Para lógica e componentes da aplicação.
- **HTML5 & CSS3** – Estrutura e estilo básicos.

---

## 🚀 Funcionalidades

- Exibição de produtos Apple em cards minimalistas.
- Layout totalmente responsivo para diferentes dispositivos.
- Navegação simples e intuitiva.
- Design inspirado na estética clean da Apple.
